# customer-review-sentiment-analyzer
A Python NLP project that analyzes sentiment in customer reviews.

Purpose: Analyze customer reviews using positive and negative word lists.
Features: Count matching words, handle capitalization and punctuation at word edges, reject empty input, and display a sentiment label.
How to run: py app.py
Limitations: It only recognizes words in your lists and doesn’t understand context—“not good” still gets labeled positive.
